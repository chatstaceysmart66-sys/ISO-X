# معايير تجربة المستخدم — ISO-X 0.4.0

## المرجع والملكية

- مرجع HTML المحفوظ مصدر تصميم فقط؛ لا يعمل كـWebView أو سطح مكتب أو mock طرفية.
- Openbox يدير النوافذ، وPCManFM يدير سطح الملفات، وTint2 الشريط، وGTK التطبيقات الأصلية، وPlymouth مرحلة الإقلاع.
- لا تعرض واجهتان الوظيفة نفسها في الوقت نفسه، ولا تعرض الخدمات أو الأجهزة غير الموجودة كأنها متاحة.

## الألوان والتخطيط

- لوحة المرجع: الأزرق `#1e6bff`، السماوي `#4fb4ff`، النص `#cfeaff`، والزجاج الكحلي الداكن.
- الشريط السفلي 48px في Tint2؛ تظل الساعة ومؤشر AR/EN وصينية النظام أدوات نظام فعلية.
- القائمة تستخدم GTK launcher: ثمانية تطبيقات مثبتة في العرض الأول، ثم المزيد والرجوع والبحث.
- الواجهة عربية أولاً وتدعم الإنجليزية؛ يجب أن يحترم ترتيب النصوص والحقول RTL/LTR دون قلب الرموز أو اختصارات لوحة المفاتيح.
- لا تختفِ الأيقونات أو النوافذ خلف الشريط، ولا تستبدل وظائف Openbox الحقيقية بعناصر HTML شكلية.

## الصور والدقات

- لا تمدد صورة الشعار أو الخلفية. الخلفية تستخدم `fit`؛ مشهد Plymouth يستخدم احتواءً متناسباً ومتمركزاً.
- صور المرجع الأصلية: الخلفية ومشهد الإقلاع 1920×1080، وعلامة التنين 100×106. لا توصف الصور الصغيرة أو 1920×1080 بأنها أصول 4K.
- المقاسات المستهدفة لعقود الملاءمة: 1366×768، 1280×720، 1920×1080، 1920×1200، 2560×1440، 3840×2160.
- النجاح الحسابي لا يعوض مراجعة لقطات حقيقية؛ تسجيل اللقطات وHiDPI وعتاد العرض يبقى شرط قبول منفصلاً.

## التفاعل والسلامة

- أزرار التطبيقات تستدعي Desktop Entries حقيقية؛ وظائف الملفات والشبكة والصوت والطاقة تبقى مربوطة بخدمات النظام وصلاحيات المستخدم.
- لا تنفذ JavaScript أوامر shell، ولا تُشغّل الطرفية النموذجية أو الحاسبة المبنية على `Function()` في المرجع.
- لا تعرض اتصال Wi-Fi أو شحنة بطارية أو سطوعاً أو حالة Bluetooth افتراضية. أخفِ الوظيفة عند غياب الجهاز أو الخدمة، أو اشرح عدم توفرها.
- انتقال الإقلاع يتبع جاهزية الخدمات والجلسة؛ لا تستخدم مؤقتاً لإظهار تقدم وهمي أو تأخير الانتقال.
- سجّل الخطأ للمستخدم بوضوح؛ لا تخفِ أعطال الخدمات ولا تزيل آليات الإنقاذ.

## أدلة التحقق

عقود المصدر واختبار استخراج الصور يثبتان بيانات الملفات وإعدادات الملاءمة فقط. لا توجد في هذه الجولة لقطات جديدة أو ISO مبنية؛ لذلك تبقى المعاينة المرئية، DPI، تشغيل الخدمات، والإقلاع على BIOS/UEFI غير متحققة حتى تُنفذ على ISO نفسها.
