# أدلة واجهة متجر ISO-X

هذه اللقطات مأخوذة من `StoreWindow` الفعلية عبر GTK 3 تحت Xvfb:

- `store-ar.png`: الواجهة العربية، واتجاه RTL، وست بطاقات.
- `store-en.png`: الواجهة الإنجليزية، واتجاه LTR، وست بطاقات.

أُعيد التقاط الصورتين بعد تحديث شعار رأس المتجر عبر:

```bash
xvfb-run -a -s '-screen 0 1366x1024x24' /usr/bin/python3 tests/capture_store_ui.py docs/ui-evidence
```

يستخدم الالتقاط backend اختبارياً ببيانات محلية ثابتة وأسماء توضيحية، لتوثيق شكل الواجهة فقط. الأسماء والأوصاف والإصدارات والأحجام والأيقونات في البطاقات ليست كتالوجاً رسمياً ولا تثبت وجود الحزم أو نجاح تثبيتها. كما أن اللقطات ليست من ISO مبنية ولا من جلسة Debian Trixie؛ زر APT يعرض حالة المضيف الذي التُقطت عليه الصورة.

تثبت اللقطات عرض البطاقات والاتجاهين بصرياً، ولا تستبدل اختبارات البحث أو عمليات مدير الحزم الفعلية أو الإقلاع على الصورة النهائية.
