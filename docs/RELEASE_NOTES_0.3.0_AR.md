# ISO-X 0.3.0 — ملاحظات الإصدار

## ملاحظات تاريخية عن المصدر 0.3.0

هذه ملاحظات محفوظة للمرجع، وقد صحح إصدار المصدر 0.3.1 وصف بعض الآليات حتى لا تُعرض آلية تمويه العلامة كتشفير، ولا تُنسب للخزنة خوارزمية غير مطبقة.

## ➕ ميزات جديدة (بناءً على طلب العميل)
1. **مركز التطبيقات** (`isox_appcenter.py`): تثبيت/إزالة تطبيقات حقيقية عبر apt
   مع إنشاء اختصارات تلقائية على سطح المكتب (Firefox, LibreOffice, VLC, GIMP...).
2. **قياس سرعة الإنترنت** (`isox-speedtest`): تنزيل وقياس Mbps + Ping، وضع GUI وCLI، صفر تتبع.
3. **حرق USB والإقلاع من الفلاشة** (`isox-write-usb`): حرق بـ dd + حماية من مسح
   القرص الخطأ + خيار `persistence` لحفظ التعديلات على الفلاشة.
4. **تشفير متعدد الطبقات**:
   - وحدة النواة 0.3.0: تمويه/ترميز attribution باستخدام XOR؛ هذا ليس تشفيرًا أمنيًا ولا يمنع مالك الجهاز من تعديل النواة أو الإقلاع.
   - خزنة الملفات في المصدر الحالي 0.3.1: AES-256-CBC مع PBKDF2-HMAC-SHA256 وHMAC-SHA256 للتحقق من السلامة؛ لا تصف هذه النسخة بأنها AES-GCM.
   - `secureboot-enroll.sh`: أداة تحقق من تطابق مفتاح وشهادة فقط؛ لا تسجل مفاتيح UEFI ولا تفعّل Secure Boot. ملاحظات الإصدار السابقة بالغت في وصفها.
5. **تكامل واجهة GTK**: أزرار المتصفح الكامل وقياس السرعة في صفحة الويب.

## ⚠️ ما لم يتغير (بصدق)
- لم يُبنَ ISO فعليًا في هذه البيئة — نفس سكربت البناء يبنيه على مضيف Linux.
- مشهد Bevy ما زال ترحيبيًا بصريًا، ليس greeter مصادقة.
- أهداف 30 ثانية / 180MB تتطلب قياسًا على جهاز حقيقي (2-core/1GB).

## شحن الفلاشة
```bash
sudo ./scripts/write-usb.sh ISO-X-0.3.0-live-amd64.iso persistence
```
