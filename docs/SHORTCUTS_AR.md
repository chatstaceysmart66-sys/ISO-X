# اختصارات لوحة المفاتيح — ISO-X 0.4.0

## تبديل العربية والإنجليزية

- **Alt الأيسر + Shift الأيسر**: التبديل بين تخطيطي `ara` و`us`.
- يعرض مؤشر لوحة المفاتيح في الشريط `AR` أو `EN`، والنقر عليه يبدّل التخطيط.
- يُحفظ التخطيط النشط في `~/.config/iso-x/keyboard-layout` عند التبديل، ويُستعاد عند بدء جلسة Openbox. مع Persistence مفعّلة، يفترض أن يبقى هذا الملف؛ لم يُثبت ذلك بعد بإعادة إقلاع ISO.
- تخطيط الإدخال مستقل عن لغة واجهة النظام، ويبدأ التخطيط الافتراضي بالعربية مع إتاحة الإنجليزية.

## النوافذ وسطح المكتب

| الاختصار | الوظيفة |
|---|---|
| `Alt+Tab` / `Alt+Shift+Tab` | النافذة التالية / السابقة |
| `Alt+F4` | إغلاق النافذة النشطة |
| `Super+E` | فتح مدير الملفات |
| `Super+W` | فتح مرحبًا ISO-X |
| `Super+R` | فتح تشغيل أمر |
| `Super+D` | إظهار سطح المكتب أو استعادة النوافذ |
| `Super+L` | قفل الجلسة |
| `Super+A` | تبديل وضع الطيران |
| `Super+I` | فتح إعدادات سطح المكتب |
| `Super+Enter` | فتح الطرفية |
| `Super+Left` / `Super+Right` | تثبيت النافذة يسارًا / يمينًا |
| `Ctrl+Super+Escape` | فتح مدير المهام |
| `Print` | فتح أداة لقطة الشاشة |

تُفسّر الاختصارات أعلاه في Openbox؛ قد تختلف نتيجة اختصارات التطبيقات أو تتعارض معها بحسب البرنامج النشط.
