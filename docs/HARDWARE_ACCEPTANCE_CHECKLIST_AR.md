# قائمة قبول ISO-X على جهاز حقيقي

**الحالة الأولية لكل البنود: لم يُختبر بعد.** يجب إجراء اختبارات التثبيت على جهاز/قرص تجريبي أو بيئة يمكن مسحها؛ لا تبدأ المثبّت على قرص يحوي ملفاتك المهمة. سجّل طراز الجهاز، CPU، مقدار RAM، كرت الشبكة/الصوت/الرسوميات، نوع الإقلاع، إصدار ISO وبصمة SHA-256 مع كل نتيجة.

| المجال | التجربة المطلوبة | النتيجة |
|---|---|---|
| سلامة الوسيط | قارن SHA-256 للـ ISO مع ملف `.sha256`؛ اكتب USB بأداة مناسبة وأعد قراءته | لم يُختبر بعد |
| BIOS/Legacy | إقلاع مباشر من USB، ظهور قائمة الإقلاع، تحميل kernel وinitramfs والوصول إلى LightDM | لم يُختبر بعد |
| UEFI | إقلاع من USB على UEFI؛ اختبر Secure Boot OFF وON بشكل منفصل | لم يُختبر بعد |
| التوافق مع Secure Boot | تحقق أن الوحدة تقبلها kernel فقط إذا كانت شهادة التوقيع موثوقة؛ وثّق حالة Secure Boot و`dmesg` | لم يُختبر بعد |
| سطح المكتب | تسجيل الدخول إلى الجلسة، ظهور خلفية ISO-X، الشريط والقائمة والأيقونات وفتح لوحة الترحيب | لم يُختبر بعد |
| الأداء وRAM | سجّل `free -h`, `systemd-analyze`, وقت الوصول إلى سطح المكتب، حجم ISO، RAM عند الخمول وعند فتح Firefox | لم يُختبر بعد |
| 2GB RAM | كرر الإقلاع والاستخدام بذاكرة فعلية 2GB أو بتحديد QEMU إلى 2048MB؛ راقب OOM والتبديل وZRAM | لم يُختبر بعد |
| شبكة سلكية | توصيل Ethernet، DHCP، DNS، فتح صفحة ويب، فصل/إعادة توصيل | لم يُختبر بعد |
| Wi-Fi | اكتشاف الشبكات، كلمة مرور صحيحة وخاطئة، فصل/إعادة اتصال، إيقاف/تشغيل وضع الطيران | لم يُختبر بعد |
| Bluetooth | تشغيل المحول، الاقتران، نقل/اتصال جهاز مدعوم | لم يُختبر بعد |
| لوحة المفاتيح | تأكد من العربية والإنجليزية، تبديل Alt+Shift، كتابة عربية في GTK وFirefox والطرفية | لم يُختبر بعد |
| خطوط واتجاه | تحقق بصريًا من العربية، التشكيل، RTL، التبويبات والنص المختلط في الواجهة والمتصفح | لم يُختبر بعد |
| المتصفح | افتح Firefox ESR وتأكد من الصفحة المحلية، البحث يدويًا، الخطوط، صفحة HTTPS، التنزيل والعودة | لم يُختبر بعد |
| متصفح خفيف | افتح NetSurf وتحقق من صفحات بسيطة، مع الاعتراف بأن دعم JavaScript والمواقع الحديثة محدود | لم يُختبر بعد |
| الصوت | شغّل ملفًا صوتيًا، غيّر مستوى الصوت ومخرج الصوت، اختبر سماعة/HDMI و`wpctl status` | لم يُختبر بعد |
| ميكروفون/كاميرا | اختبر `guvcview` أو `cheese` بموافقة المستخدم؛ تحقق من الأذونات وعدم وجود مؤشرات زائفة | لم يُختبر بعد |
| الطباعة | اكتشاف طابعة فعلية أو شبكة، إرسال صفحة اختبار، التحقق من CUPS والسجل | لم يُختبر بعد |
| ملفات وUSB | فتح Thunar، mount/unmount آمن، قراءة ونسخ ملف، تحقق من صلاحيات المستخدم | لم يُختبر بعد |
| برامج أساسية | افتح الطرفية والمحرر والآلة الحاسبة ومدير المهام والإعدادات ومركز التطبيقات دون أخطاء | لم يُختبر بعد |
| خزنة ISO-X | أنشئ خزنة اختبار، أغلقها، أعد فتحها، اختبر كلمة مرور خاطئة وملفًا معدلًا؛ لا تستخدم كلمة مرور حقيقية | لم يُختبر بعد |
| العلامة/الوحدة | افحص رسالة الوحدة وسجل kernel، التوقيع والـ initramfs؛ تحقق من فشل الإقلاع الآمن إذا أزيلت الوحدة أو عُدلت | لم يُختبر بعد |
| قفل/جلسة | قفل الشاشة، خروج من الجلسة، العودة، تبديل المستخدم إن كان متاحًا | لم يُختبر بعد |
| إطفاء وإعادة تشغيل | جرّب إطفاءً وإعادة تشغيل من القائمة ومن الطرفية؛ تأكد من إطفاء الجهاز فعليًا | لم يُختبر بعد |
| المثبّت | فقط على قرص تجريبي: ثبّت النظام إلى القرص، أقلع من القرص، تحقق من المستخدم والشبكة والصوت والتحديثات | لم يُختبر بعد |
| سجلات الأعطال | بعد كل فشل احفظ `journalctl -b`, `dmesg`, `/var/log/installer/` عند وجوده، وصورة شاشة بدون بيانات شخصية | لم يُختبر بعد |

لا يتحول أي بند إلى Pass إلا بتسجيل الأمر/التجربة، النتيجة، وملف الدليل. نجاح الاختبارات الساكنة أو QEMU لا يحل محل اختبار العتاد الحقيقي.
